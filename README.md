# Agentic Comic Studio 🎭✨  
An AI-powered comic creation workflow that turns historical figures, characters, or stories into complete comic panels — fully agentic, fully automated.

## 🚀 Features
- 🧠 **Agentic Pipeline** – Multi-step agents for research, character building, scripting, and panel generation.  
- 🎨 **Image Generation** – Generates consistent characters across panels.  
- 📖 **Episode Builder** – One-click prompt that produces entire story arcs.  
- 🧩 **Modular Design** – Plug in any LLM (GPT, Claude, Gemini) or image model (Flux, SDXL).  
- 🗃️ **Export Options** – Save panels as images, storyboards, or full comic pages.
